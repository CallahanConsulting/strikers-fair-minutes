# Lee County Strikers — Fair Minutes

A phone-friendly playing-time planner for youth soccer coaches. Enter team size, players on the field, periods, period length, and water breaks, and it builds a rotation that spreads minutes as evenly as possible.

Live app: https://callahanconsulting.github.io/strikers-fair-minutes/

Share with coaches: https://callahanconsulting.github.io/strikers-fair-minutes/bookmark.html (shows how to add it to the home screen with the Strikers crest icon)

Everything runs in the browser; rosters are saved only on each coach's own device.
